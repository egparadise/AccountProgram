# 정산ON — 회계 정산 프로그램

WEHAGO 홈피스의 공개 화면과 설치된 Chrome PWA를 REA로 관찰한 뒤, 확인된 회계 업무 흐름을 독립적으로 재구현한 로컬 우선 웹 앱입니다. 원 서비스의 코드, 상표, 비공개 API 또는 사용자 데이터를 복사하지 않습니다.

## 구현 기능

- 경영 대시보드: 매출, 비용, 손익, 미수금, 월별 추이
- 거래·전표: 매입/매출/경비/입출금, 증빙·결제 상태, 복식부기 자동 분개
- 월 정산: 손익, 부가세, 채권·채무 점검, 월 마감 및 취소
- 세금계산서: 매출/매입 계산서 작성과 발행·수금 상태
- 인사·급여: 직원 등록, 월 급여 계산, 지급 완료
- 거래처: 매출처/매입처 정보와 잔액 관리
- 보고서: 손익계산서, 부가세 요약, 합계잔액시산표, CSV 내보내기
- PWA: 설치 가능한 독립 창, 앱 셸 오프라인 캐시

데이터는 브라우저 `localStorage`에 저장됩니다. 데모/소규모 단일 사용자 용도이며, 실제 세무 신고나 다중 사용자 운영에는 서버 데이터베이스, 인증, 감사로그, 백업, 전자신고기관 연동이 추가로 필요합니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드와 테스트:

```bash
npm test
npm run build
npm run preview
```

기본 개발 주소는 `http://localhost:4173`입니다.

Windows에서는 `Start-AccountProgram.ps1`을 실행하면 빌드된 앱의 로컬 서버가 숨김으로 시작되고 Chrome 앱 창이 열립니다. 바탕화면 바로가기도 이 실행기를 사용합니다.

## 구조

- `src/lib/accounting.ts`: 부가세, 자동 분개, 월 집계, 시산표
- `src/store.tsx`: 로컬 영속 상태와 도메인 액션
- `src/App.tsx`: 업무 화면과 입력 흐름
- `src/data/sample.ts`: 비식별 샘플 데이터
- `public/manifest.webmanifest`, `public/sw.js`: PWA 설치 및 오프라인 셸

상세한 역공학 근거와 기능 매핑은 별도 Obsidian 분석 문서에 있습니다.
